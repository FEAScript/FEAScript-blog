# FEAScript-blog

[![Website](https://img.shields.io/website?url=https%3A%2F%2Fblog.feascript.com%2F)](https://blog.feascript.com/)

FEAScript is a finite element simulation library built in JavaScript. This is the source code of the FEAScript [blog](https://blog.feascript.com/).

## Sitemap

`sitemap.xml` is generated at build time by the `jekyll-sitemap` plugin (supported by GitHub Pages), from the URLs Jekyll gives the posts and pages, so new posts are listed without editing anything. A post's `<lastmod>` is its `date`; after a substantial edit, add `last_modified_at: YYYY-MM-DD` to its front matter. A page that should not be indexed gets `sitemap: false` (as `404.html` has).
